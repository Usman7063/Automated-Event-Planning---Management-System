AUTOMATED EVENT PLANNING & MANAGEMENT SYSTEM
=============================================

Project Overview
----------------
Automated Event Planning & Management System is a web-based project developed
to help users plan and manage events through an online platform. It brings
event-related services and booking features together in one system.

Main Features
------------
- User registration, login and authentication
- Event booking workflow
- Event and vendor/service management
- Service comparison
- Budget estimation
- Booking management
- Payment page
- User feedback and contact functionality
- Admin dashboard and management features
- Chatbot interface with English/Urdu support

Technologies Used
-----------------
- HTML
- CSS
- JavaScript
- PHP
- MySQL
- XAMPP (Apache and MySQL)
- Bootstrap

Project Structure
-----------------
event-system/
    backend/
        admin/       Admin-side PHP functionality
        auth/        User authentication functionality
        ...          Booking, payment, feedback and other PHP files
    frontend/
        ...          HTML, CSS, JavaScript and image assets

How to Run Locally
------------------
1. Install XAMPP.
2. Copy the event-system folder into the XAMPP htdocs directory.
3. Start Apache and MySQL from the XAMPP Control Panel.
4. Configure the database connection in backend/db.php to match your
   local MySQL settings.
5. Create/import the project's database in phpMyAdmin. The database
   schema or SQL export should be obtained from the project developers
   if it is not included in this repository.
6. Open the project through your browser using the appropriate localhost
   URL for the frontend entry page.
